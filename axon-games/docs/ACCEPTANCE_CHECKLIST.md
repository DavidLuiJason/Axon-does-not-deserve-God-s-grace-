# Acceptance checklist

- [x] 150 unique catalogue entries are present.
- [x] Static, responsive browser UI and shared challenge runtime are included.
- [x] Local settings/history and JSON export are implemented.
- [x] No third-party runtime dependencies or network requests are required.
- [ ] Every game mechanic fully matches its title (especially named board games).
- [ ] Every engine has unit tests and edge-case coverage.
- [ ] Automated browser play-through of every entry.
- [ ] Storage corruption, interruption, quota and recovery tests.
- [ ] AXON host integration verified against the actual current source.
- [ ] Physical older Android phone performance and memory tests.
- [ ] Accessibility audit and manual keyboard/screen-reader checks.

The unchecked items are release blockers for claiming the complete 150-game system.
