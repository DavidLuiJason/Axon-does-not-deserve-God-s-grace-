# SI5 PICTURE TEXT + SI4 PHONE SELF-TEST (D47, 2026-11-14)
PLAIN: AXON can read the words inside pictures on a screen (a sign, a banner, a screenshot) and can run a one-tap self-test on your phone that proves the whole screen-reading chain works.
DECISION (D47, owner delegated): on-device ML Kit text recognition, Latin script (English, Yoruba, Igbo, Hausa, French and other Latin-script languages), model bundled so it works offline and sends nothing out. Other scripts (Arabic, Chinese, etc.) are NOT covered yet. Describing what a picture shows (not its words) stays with the brain's own picture references and is NOT built.
HOW: the reader finds picture regions (SI3c); AXON takes ONE screenshot in memory (Android 11+, accessibility screenshot, nothing saved), cuts each region out, reads its words, throws the pixels away, and returns text only. Card-like numbers are removed from the text. Password boxes are never read. Protected windows (for example banking apps that block screenshots) return "screen-protected".
