# AXON REAL-MESSAGE LIST (draft by the Director, 2026-10-24, v2)

WHAT THIS IS: about 100 messages you might really type to AXON. They become the test set for the brain (B03B and later). Real examples beat invented ones.

WHAT YOU DO (about 10 minutes):
1. Read each line. If it is not how you would write it, change it into how YOU would write it (your spelling, your accent, your slang).
2. Lines that start with "NO:" are messages AXON should REFUSE or NOT obey. If you disagree with a "NO:", delete the "NO:". If you think another line should be refused, add "NO:" to it.
3. Add 20 or more of your own at the bottom, especially messy ones.
4. Send the file back to me (or to the next account).
