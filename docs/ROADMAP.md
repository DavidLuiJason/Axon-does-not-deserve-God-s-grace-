## 2. WHAT AXON IS FOR, AND HOW IT MUST FEEL
AXON is an Android app (Capacitor, React, TypeScript; built in Google AI Studio, kept in GitHub, built to an APK by GitHub Actions): an intelligent, truthful, conversational assistant with an English dictionary as its understanding, plus tools and media. It reads what is said and what came before, finds several instructions in one message, answers each, notices mistakes, says plainly what it does not know, and never claims an ability it lacks. It uses explicit, testable parts and may add a model later as a second tier supervised by those checks. The real work is the language layer; the dictionary is its first ingredient.
**Who AXON serves (owner, 2026-10-22, binding):** AXON works for its owner, comes first, and gets the owner the results asked for inside the Charter and the truth. **Design philosophy (owner, 2026-10-16, binding on every screen):** simple, clear, organised, professional; a page is understood at a glance (what it does, what the person can do, where to go next). Show the few main choices first; reveal the rest only when the person goes in. A pretty screen that is hard to read is a failed screen. **One look everywhere (2026-10-17; full text annex A13):** the same header band on every screen, the back control a slim row UNDER it; lists are plain rows (icon, name, chevron), no boxed cards, no per-row "Coming soon" badges; a header may fold away ONLY on editor screens.
