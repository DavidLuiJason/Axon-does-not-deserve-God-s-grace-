## 2. WHAT AXON IS FOR, AND HOW IT MUST FEEL
AXON is an Android app (Capacitor, React, TypeScript; built in Google AI Studio, kept in GitHub, built to an APK by GitHub Actions): an intelligent, truthful, conversational assistant with an English dictionary as its understanding, plus tools and media.
