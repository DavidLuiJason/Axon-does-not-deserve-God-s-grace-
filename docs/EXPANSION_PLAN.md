How to read a group: HOME = layer of the finished AXON (roadmap section 6: 0 Ground, 1 Knowledge slot, 2 Reading language, 3 Understanding, 4 Voice, 5 Reach). NEEDS = what must be proven first. PROOF = what decides, never the author's own claim. VERDICT = WORKS / WORKS DIFFERENTLY / WORKS ONLY IF / CANNOT JUDGE.
